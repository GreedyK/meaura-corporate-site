# News 記事の投稿方法

このフォルダに **1記事 = 1 JSON ファイル** で記事を追加します。
ファイルを置くだけでサイトに反映されます（`index.ts` の編集は不要です）。

## 手順

1. このフォルダ（`content/news/posts/`）に新しい JSON ファイルを作成する
2. **ファイル名** を slug（URL用ID）にする
   - 英数字とハイフンのみ（例: `new-service-launch.json`）
   - 表示URL: `/news#new-service-launch`
3. 下記テンプレートをコピーして内容を書く
4. 保存後、開発サーバーを再起動するか、本番へデプロイする

## ファイル名のルール

| 項目 | ルール |
|------|--------|
| 形式 | `slug.json` |
| slug | 英小文字・数字・ハイフン（例: `jibun-maker-update`） |
| 日本語 | ファイル名には使わない |

## テンプレート

```json
{
  "date": "2026.08.29",
  "title": "記事タイトル",
  "excerpt": "カードに表示する概要文（1〜2文程度）",
  "category": "お知らせ",
  "sections": [
    {
      "heading": "見出し",
      "paragraphs": [
        "本文の段落1",
        "本文の段落2"
      ],
      "points": [
        "箇条書き1（任意）",
        "箇条書き2"
      ]
    }
  ]
}
```

## 各項目の説明

| 項目 | 必須 | 説明 |
|------|------|------|
| `date` | ○ | 表示日付（`YYYY.MM.DD` 形式） |
| `title` | ○ | 記事タイトル |
| `excerpt` | ○ | カード折りたたみ時に表示する概要 |
| `category` | ○ | `"お知らせ"` / `"プロジェクト"` / `"コラム"` のいずれか |
| `sections` | ○ | 本文ブロックの配列（1つ以上） |
| `sections[].heading` | ○ | セクション見出し |
| `sections[].paragraphs` | ○ | 段落の配列（文字列） |
| `sections[].points` | × | 箇条書き（省略可） |

## 表示順

- 日付の **新しい順** に自動で並びます
- 同じ日付の場合はファイル名（slug）の昇順です

## 既存記事の編集

該当する JSON ファイルを直接編集して保存してください。

## 注意

- JSON の構文エラー（カンマの付け忘れなど）があるとビルドに失敗します
- 文字列は `"`（ダブルクォート）で囲んでください
- 最後の項目の後にカンマを付けないでください
